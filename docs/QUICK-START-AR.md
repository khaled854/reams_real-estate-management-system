# 🏠 سوق العقارات — دليل التشغيل السريع

> **لمن يريد تشغيل النظام بسرعة — ورقة واحدة**

---

## ✅ المتطلبات (مرة واحدة فقط)

| البرنامج | الرابط | ملاحظة |
|---|---|---|
| **Node.js** | https://nodejs.org | اختر: **LTS** |
| **XAMPP** | https://www.apachefriends.org | يحتوي MySQL |

---

## 🚀 التشغيل اليومي (3 خطوات فقط)

### الخطوة 1 — شغّل MySQL
افتح **XAMPP Control Panel** ← اضغط **Start** بجانب **MySQL**
✅ يصبح اللون **أخضر**

### الخطوة 2 — شغّل السيرفر
افتح مجلد المشروع ← افتح مجلد `scripts` ← انقر **مرتين** على:
```
start-server.bat
```
✅ تظهر رسالة: `Server running on http://0.0.0.0:5000`

### الخطوة 3 — افتح النظام
افتح المتصفح ← اكتب:
```
http://localhost:5000
```
✅ تظهر صفحة تسجيل الدخول

---

## 🔐 بيانات الدخول الافتراضية

| الحقل | القيمة |
|---|---|
| البريد الإلكتروني | `admin@test.com` |
| كلمة المرور | `Admin@123456` |

> **⚠️ غيّر كلمة المرور فور أول دخول**

---

## 🌐 للوصول من جهاز آخر على نفس الشبكة

1. افتح مجلد `scripts` ← انقر **مرتين** على `find-ip.bat`
2. ستظهر عناوين IP — ابحث عن الرقم الذي يبدأ بـ `192.168.`
3. على الجهاز الآخر افتح المتصفح وأكتب: `http://192.168.X.X:5000`

---

## 🛑 إيقاف النظام

في نافذة الـ `start-server.bat` — اضغط:
```
Ctrl + C
```
ثم اضغط **Y** ← ثم أوقف **MySQL** من XAMPP
