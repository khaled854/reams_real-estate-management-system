دليل تثبيت وتشغيل نظام إدارة العقارات REMS لأول مرة
══════════════════════════════════════════════════════

⚠ تنبيه مهم قبل البدء: بيانات الدخول الافتراضية
─────────────────────────────────────────────────
النظام يأتي ببيانات دخول افتراضية لأول مرة فقط:

  البريد الإلكتروني : admin@test.com
  كلمة المرور       : Admin@123456

هذه البيانات للإعداد الأولي فقط.
يجب تغيير كلمة المرور فور أول تسجيل دخول
قبل أن يستخدم النظام أي موظف في الشركة.

كيفية التغيير بعد الدخول:
  المستخدمون ← اضغط على حسابك ← تغيير كلمة المرور

══════════════════════════════════════════════════════

قبل البدء

تأكد من وجود:

✅ جهاز Windows داخل الشركة ليكون الجهاز الرئيسي للنظام.
✅ إنترنت لتحميل البرامج المطلوبة فقط في أول مرة.
✅ فلاشة أو ملف النظام المرسل من المطور.

بعد الانتهاء من التثبيت، الموظفين لن يحتاجوا للإنترنت لتشغيل النظام داخل الشركة.

الجزء الأول: تحميل البرامج المطلوبة

نحتاج تثبيت 3 برامج فقط:

XAMPP (لتشغيل قاعدة البيانات)
Node.js (لتشغيل النظام)
Google Chrome (لفتح النظام)

─────────────────────────────────────────────────
1) تحميل وتثبيت XAMPP
─────────────────────────────────────────────────
الخطوة 1: فتح رابط التحميل

افتح Google Chrome.

اضغط على الرابط:
https://www.apachefriends.org/download.html

الخطوة 2: اختيار النسخة

ستظهر صفحة التحميل.
اختار Windows ثم اضغط Download.
انتظر حتى يكتمل التحميل.
سيكون اسم الملف قريب من:
xampp-windows-x64-installer.exe

الخطوة 3: تثبيت XAMPP

افتح ملف التحميل.
اضغط Yes إذا ظهرت رسالة Windows.
اضغط Next في اختيار المكونات، اترك كل شيء كما هو.
اضغط Next.
مكان التثبيت اتركه كما هو: C:\xampp
ثم Next → Next → Install.
انتظر حتى ينتهي.
بعد انتهاء التثبيت اضغط Finish.
سيفتح برنامج: XAMPP Control Panel

─────────────────────────────────────────────────
2) تحميل وتثبيت Node.js
─────────────────────────────────────────────────
افتح: https://nodejs.org/
اضغط على LTS وليس Current.
سيتم تحميل ملف مثل: node-vxx.x.x-x64.msi

تثبيت Node.js:
افتح الملف.
اضغط Next.
وافق على الشروط: ✅ I accept the terms
ثم Next.
اترك مكان التثبيت كما هو: C:\Program Files\nodejs\
اضغط Next → Install.
بعد الانتهاء: Finish.

─────────────────────────────────────────────────
3) تحميل Google Chrome
─────────────────────────────────────────────────
افتح: https://www.google.com/chrome/
اضغط Download Chrome ثم افتح الملف.
اضغط Install وانتظر حتى ينتهي.

══════════════════════════════════════════════════════

الجزء الثاني: وضع ملفات النظام

بعد استلام فولدر النظام:
انسخه إلى القرص C: ليصبح: C:\REMS

لا تغير اسم الفولدر.

يجب أن يكون الشكل:
C:\REMS
  backend
  frontend
  database
  scripts

══════════════════════════════════════════════════════

الجزء الثالث: تجهيز قاعدة البيانات

تشغيل XAMPP:
افتح Start Menu، اكتب XAMPP، اضغط XAMPP Control Panel.
ستظهر نافذة. اضغط Start بجانب MySQL.
يجب أن يصبح باللون الأخضر: ✅ MySQL Running

ملاحظة: Apache ليس مطلوباً لتشغيل النظام.
يكفي تشغيل MySQL فقط.

══════════════════════════════════════════════════════

الجزء الرابع: تجهيز النظام

اذهب إلى: C:\REMS
اضغط داخل المكان الفارغ كليك يمين.
اختر: Open in Terminal

اكتب:
npm install --prefix backend

اضغط Enter وانتظر حتى ينتهي.

بعدها اكتب:
npm install --prefix frontend

اضغط Enter وانتظر حتى ينتهي.

══════════════════════════════════════════════════════

الجزء الخامس: تجهيز قاعدة البيانات

في نفس النافذة اكتب:
cd backend

ثم اكتب:
node scripts\migrate-live-db.js

انتظر حتى ينتهي. هذا ينشئ جداول قاعدة البيانات.

بعدها اكتب:
node scripts\seed-admin.js

هذا ينشئ حساب المدير الأول.

⚠ ستظهر رسالة تؤكد إنشاء الحساب:
   البريد    : admin@test.com
   كلمة المرور : Admin@123456

تذكر: يجب تغيير كلمة المرور هذه فوراً بعد أول دخول.

══════════════════════════════════════════════════════

الجزء السادس: تشغيل النظام

ارجع إلى فولدر C:\REMS في نافذة Terminal:
اكتب: cd ..

ثم اكتب:
npm run build

انتظر حتى ينتهي (يستغرق دقيقة أو دقيقتين).

بعدها ادخل فولدر C:\REMS\backend:
اكتب: cd backend

ثم اكتب:
npm start

إذا ظهرت رسالة:
Server running on port 5000

النظام جاهز.

⚠ لا تغلق هذه النافذة. إغلاقها يوقف النظام.

══════════════════════════════════════════════════════

الجزء السابع: فتح النظام

افتح Google Chrome.
اكتب: http://localhost:5000
اضغط Enter.
ستظهر صفحة تسجيل الدخول.

ادخل البيانات:
  البريد      : admin@test.com
  كلمة المرور : Admin@123456

⚠ بعد الدخول مباشرة: اذهب إلى المستخدمون وغيّر كلمة المرور.

══════════════════════════════════════════════════════

تشغيل النظام من أجهزة الموظفين

من الجهاز الرئيسي:
اضغط Windows + R
اكتب: cmd
ثم Enter.
اكتب: ipconfig
ابحث عن: IPv4 Address
مثال: 192.168.1.6

على جهاز الموظف افتح Chrome واكتب:
http://192.168.1.6:5000

(استبدل 192.168.1.6 بالعنوان الذي ظهر عندك)

بعد أول تثبيت — الروتين اليومي

كل يوم للمشغّل يعمل فقط:

1. يفتح XAMPP Control Panel
2. يضغط Start عند MySQL (حتى يصبح أخضر)
3. يفتح ملف: start-server.bat
   (أو يذهب إلى C:\REMS\backend ويكتب: npm start)
4. يفتح: http://localhost:5000

ملاحظات مهمة للمشتري

1. النسخ الاحتياطي يدوي
   النظام لا يحتفظ بنسخ احتياطية تلقائياً.
   يجب على المسؤول تشغيل سكريبت النسخ الاحتياطي بانتظام:
   C:\REMS\scripts\backup-database.bat
   احفظ الملف الناتج على فلاشة أو مشاركة شبكية.

2. وحدة العقود غير متاحة في هذا الإصدار
   النظام يدير العقارات والعملاء والمواعيد والتقارير بشكل كامل.
   وحدة العقود والمدفوعات ستكون في تحديث قادم.
   أرقام "إيرادات الشهر" و"العقود النشطة" في لوحة التحكم
   ستظهر دائماً صفراً في هذا الإصدار.

3. إعادة تعيين كلمة المرور يدوية
   إذا نسي موظف كلمة مروره، يطلب من المدير إعادة تعيينها
   من صفحة: المستخدمون → تعديل الحساب → إعادة تعيين كلمة المرور.
   لا يوجد "نسيت كلمة المرور" بإرسال إيميل في هذا الإصدار.
